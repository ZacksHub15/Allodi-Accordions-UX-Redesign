# Allodi Accordions Ltd. – Website UX Redesign

## Overview

This academic project explores the user experience of the
Allodi Accordions Ltd. website and proposes a redesigned
interface to improve usability, navigation and accessibility.

## Project Objectives

- Analyse the existing website and identify usability issues.
- Evaluate the website using Nielsen's 10 Usability Heuristics.
- Examine website accessibility using WCAG guidelines.
- Identify user needs through personas and user journey mapping.
- Develop a redesigned website prototype.
- Evaluate the proposed design through usability testing.

## Research Methodology

- Research type: Qualitative research
- Research approach: Secondary research
- Research focus: Website usability and user experience

## Tools and Techniques

- User-Centred Design
- Nielsen's 10 Usability Heuristics
- WCAG accessibility guidelines
- User personas
- User journey mapping
- Wireframing and prototyping
- Usability testing

## Key Learning Outcomes

- Website usability evaluation.
- User experience research.
- Identifying and analysing design problems.
- Applying accessibility principles.
- Developing user-centred design solutions.
